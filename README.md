# ThreadShot V4

이번 버전의 핵심은 "새로고침"입니다.

## 자동 새로고침 규칙
- 한국시간 오전 6시를 하루의 갱신 기준으로 사용합니다.
- 앱을 열었을 때 마지막 갱신이 오늘 오전 6시 이전이면 자동으로 새 데이터를 가져옵니다.
- 앱을 계속 켜둔 경우 10분마다 날짜 경계를 확인해서 필요하면 자동 갱신합니다.
- 상단의 `🔄 새 핫템 찾기` 버튼을 누르면 언제든 즉시 다시 검색합니다.
- 마지막 업데이트 시간을 화면에 표시합니다.

## 핫상품 데이터
- 서버에서 Google Trends 한국 RSS를 읽습니다.
- 쇼핑상품형 키워드를 우선 후보로 올립니다.
- 데이터가 부족할 경우 전환 가능성이 높은 후보 풀을 보조로 사용합니다.
- 각 후보마다 쿠팡 검색 페이지를 서버에서 best-effort 확인합니다.
- 쿠팡이 자동 요청을 차단하면 `쿠팡 최종확인`으로 표시하고, 사용자가 쿠팡 검색 버튼으로 확인할 수 있습니다.

## 실행
이 프로젝트는 Next.js 웹앱입니다.

PC 개발 실행:
1. Node.js 설치
2. 프로젝트 폴더에서 `npm install`
3. `npm run dev`
4. 브라우저에서 http://localhost:3000

## 모바일/PC 공용
무료 호스팅 서비스에 배포하면 휴대폰과 PC에서 같은 주소로 접속할 수 있습니다.
정적 HTML 파일을 폰에서 직접 여는 방식이 아니라, 서버 기능이 포함된 웹앱으로 배포해야 실시간 검색이 작동합니다.
